# 🧮 Calculadora de IMC

Uma calculadora de **IMC (Índice de Massa Corporal)** desenvolvida em **Python**, com interface criada e estilizada utilizando o **Qt Designer**.

O projeto permite informar seus dados e calcular o IMC, apresentando uma classificação de acordo com o resultado e uma faixa de peso considerada ideal.

## 🚀 Funcionalidades

* ⚖️ Informar o peso
* 📏 Informar a altura
* 👤 Informar o sexo
* 🧮 Calcular automaticamente o IMC
* 📊 Classificar o resultado
* 🎯 Informar a faixa de peso ideal

### 📋 Classificações

O resultado do IMC é dividido nas seguintes categorias:

* **Abaixo do peso**
* **Peso normal**
* **Sobrepeso**
* **Obesidade**

Após o cálculo, o sistema também apresenta a **faixa de peso ideal** de acordo com a altura informada.

## 🛠️ Tecnologias utilizadas

* **Python**
* **Qt Designer**
* **PyQt**
